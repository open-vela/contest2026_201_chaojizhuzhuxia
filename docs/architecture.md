## 二、分层说明

### 2.1 LVGL UI 层

9 个页面通过页面管理器（Page Manager）切换：

| 页面 | 文件 | 功能 |
|------|------|------|
| 锁屏 | `ui_lockscreen.c` | 背景主题、时间日期、激励语、轻触进入主菜单 |
| 主表盘 | `ui_main.c` | 实时时钟、今日学习时长、倒计时入口 |
| 倒计时 | `ui_countdown.c` | 考研倒计时进度环、精确时分秒 |
| 番茄钟 | `ui_pomodoro.c` | 圆形进度条、科目切换、开始/暂停/停止 |
| 单词 | `ui_vocabulary.c` | 卡片翻转、导航、标记按钮 |
| 音频 | `ui_audio.c` | 曲目播放、音量调节、模式切换 |
| 提醒 | `ui_reminder.c` | 闹钟列表、添加/删除/开关 |
| 计划 | `ui_study_plan.c` | 任务列表、checkbox 打卡 |
| 设置 | `ui_settings.c` | 主题切换、背景预览、版本信息 |

### 2.2 业务逻辑层

| 模块 | 文件 | 核心功能 |
|------|------|---------|
| 倒计时管理 | `countdown_manager.c` | RTC 计算、考试日期持久化 |
| 番茄钟 | `pomodoro_timer.c` | 状态机（空闲→专注→休息→完成） |
| 单词引擎 | `vocabulary_engine.c` | JSON 词库加载、标记管理 |
| 音频播放 | `audio_player.c` | NuttX Audio 框架控制 |
| 提醒管理 | `reminder_manager.c` | 闹钟增删改查、RTC 检查 |
| 复习计划 | `study_plan_manager.c` | 任务管理、日期过滤 |
| 学习记录 | `study_record.c` | 按日统计、周/月报表 |
| 震动驱动 | `vibrator.c` | PWM ioctl 控制、5 种模式 |
| 主题管理 | `theme_manager.c` | 6 套预设主题、配色持久化、激励语 |

## 三、关键设计决策

### 3.1 页面管理

采用简单页面栈方案，不依赖复杂框架：

```c
typedef enum {
    PAGE_LOCKSCREEN,
    PAGE_MAIN,
    PAGE_COUNTDOWN,
    PAGE_POMODORO,
    PAGE_VOCABULARY,
    PAGE_AUDIO,
    PAGE_REMINDER,
    PAGE_STUDY_PLAN,
    PAGE_SETTINGS,
    PAGE_MAX
} page_id_t;

void page_switch(page_id_t target);
```

### 3.2 启动与锁屏流程

开机启动顺序：
1. `theme_init()` — 加载已保存的主题配置
2. 创建锁屏页面（显示背景主题 + 时间 + 激励语）
3. 用户**轻触屏幕** → 切换到主菜单表盘

### 3.3 刷新机制

每秒一次的定时刷新（`lv_timer`）：
- 更新锁屏时钟
- 更新主表盘时钟
- 更新倒计时显示
- 更新学习时长
- 推进番茄钟计时
- 检查闹钟触发

### 3.3 功耗管理

| 场景 | 策略 | 预期功耗 |
|------|------|----------|
| 表盘显示 | 低刷新率（1Hz）、背光低亮度 | ~5mA |
| 番茄计时 | 屏幕常亮低亮度 | ~10mA |
| 单词背诵 | 触摸交互 + 全刷 | ~20mA |
| 音频播放 | 蓝牙耳机输出 | ~25mA |
| 待机休眠 | 屏幕关闭，RTC 运行 | ~0.1mA |
| BLE 同步 | 蓝牙传输 | ~15mA |

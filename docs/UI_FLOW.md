## 一、页面导航

```
┌──────────────┐
│   锁屏背景    │ ← 应用启动默认页面

       └────────────── ← ──────────┘

## 二、各页面交互流程

### 2.0 锁屏背景

```
┌─────────────────────┐
│                     │
│      08:30          │ ← 大号时间
│   2026年7月16日      │ ← 日期
│  ─────────────      │ ← 分隔线（强调色）
│  星光不负赶路人      │ ← 考研激励语（主题色）
│                     │
│     轻触进入         │ ← 提示
│    ◀ ▶ 浏览主题     │
└─────────────────────┘
    点击任意位置 → 进入主菜单
```

**主题切换**：在设置页面选择 ◀/▶ 浏览 6 套主题，点击"应用"即生效，下次亮屏显示新背景。`

```

│  └───────────────┘  │
│                     │

### 2.3 番茄自习计时器

```
┌─────────────────────┐
│    番茄自习          │
│    专注中 ✅          │ ← 状态显示
│  ┌─────────────┐    │
│  │  ╭─────╮    │    │
│  │  │ 18:42│    │    │ ← 圆形进度条
│  │  ╰─────╯    │    │
│  └─────────────┘    │
│       英语            │ ← 当前科目
│ [政治][英语][数学]    │ ← 科目选择
│  [专业课][自定义]     │
│  [▶ 开始]  [■ 停止]  │ ← 控制按钮
│  今日: 3 个番茄       │
└─────────────────────┘
```

**震动反馈**：
- 专注结束 → 三连震（300ms 震 × 3）
- 休息结束 → 长震（500ms）
- 提醒触发 → 双震（200ms 震 × 2）

## 三、交互规范

### 3.1 触摸事件

| 操作 | 响应 |
|------|------|
| 单击按钮 | 执行对应功能 |
| 单击卡片 | 翻转（单词页面） |
| 长按 | 暂未使用 |

### 3.2 颜色方案

| 用途 | 色值 | 示例 |
|------|------|------|
| 背景色 | `#1a1a2e` | 深蓝黑 |
| 卡片背景 | `#16213e` | 深蓝 |
| 强调色 | `#e94560` | 红色 |
| 成功/播放 | `#00ff88` | 绿色 |
| 警告/暂停 | `#ffaa00` | 橙色 |
| 按钮 | `#533483` | 紫色 |
| 禁用 | `#666666` | 灰色 |
